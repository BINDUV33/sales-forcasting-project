# Sales Forecasting Project

This project demonstrates a simple sales forecasting workflow for business planning.

## What is included

- Data generation and cleaning
- Time-based feature engineering
- Regression-based forecasting
- Model evaluation and business-friendly visualization
- Summary of results and planning recommendations

## Requirements

Install the required Python libraries:

```bash
pip install -r requirements.txt
```

## Run the notebook

Open `sales_forecasting.ipynb` in Jupyter Notebook or VS Code and run all cells.

## Business outcome

The notebook forecasts future sales and explains how the forecast helps with inventory, staffing, and cash flow planning.
